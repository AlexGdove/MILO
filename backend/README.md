# Backend

Заготовка. Стек будет выбран позже (варианты: NestJS / Express + Prisma + PostgreSQL).

Задачи бэкенда в будущем:

- аутентификация пользователей;
- синхронизация продуктов, дневника питания и целей между устройствами;
- база продуктов с КБЖУ.

Фронтенд уже обращается к данным через слой `frontend/src/shared/api` и `shared/lib/storage`,
поэтому подключение API потребует замены только этих модулей.
