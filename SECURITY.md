# Безопасность MILO

MILO — приложение для учёта питания и кладовой: сайт и PWA milo-app.ru, API на том же домене (`/api/v1`), приложение для Android (APK) и iOS. Личные данные пользователя (дневник, кладовая, рецепты) хранятся на устройстве; на сервере — аккаунты (почта, хэш пароля, тариф), общая база продуктов, обращения в поддержку.

## Поддерживаемые версии

| Версия | Статус               |
| :----- | :------------------- |
| 1.2.x  | ✅ поддерживается    |
| < 1.2  | ❌ не поддерживается |

Исправления выходят только для последней версии; сайт milo-app.ru всегда работает на последней версии.

## Как сообщить об уязвимости

Только приватно — через GitHub: вкладка **Security** репозитория → **Report a vulnerability** (Private vulnerability reporting). Не создавайте публичные issue и pull request с описанием уязвимости.

Что указать в сообщении:

- что затронуто (сайт, API, Android, iOS) и версию;
- шаги для воспроизведения;
- возможные последствия;
- при желании — как исправить.

## Что не нужно делать при проверке

- не обращаться к чужим аккаунтам и данным;
- не нагружать сервер (никаких DoS и массового перебора);
- не рассылать письма через формы регистрации и сброса пароля на чужие адреса;
- не публиковать сведения об уязвимости до исправления.

## Что не считается уязвимостью

- сообщения автоматических сканеров без доказательства, что проблему можно использовать;
- отсутствие отдельных заголовков безопасности без последствий;
- уязвимости в устаревших версиях (`< 1.2`).

Спасибо, что помогаете сделать MILO безопаснее.
