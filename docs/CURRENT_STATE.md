## Правила, выявленные в этой сессии

- **Разрушительные команды Prisma** (`migrate reset`, `db push --force-reset` и т. п.) Prisma блокирует для ИИ-агента; без явного согласия пользователя не запускать. Тестовая база готовится `migrate deploy` (B-13). Правка уже применённой миграции = новая миграция, а не редактирование старой.
- **PowerShell 5.1**: прямые кавычки `"` внутри here-string в `git commit -m` ломают аргументы — в сообщениях коммитов использовать «ёлочки» или одинарные. Кириллица в командах PowerShell попадает в файлы неверно — файлы писать инструментами Write/Edit. Код возврата ≠ 0 у `git push`/`git commit` бывает из-за обёртки stderr — смотреть сам вывод.
- **Бэкенд**: ESM (импорты с `.js`), Jest в ESM-режиме — нет глобального `jest.fn` (заглушки — обычные объекты); `globalSetup` Jest — обычный JS (без ts-jest). Порядок импортов правит `npx eslint <путь> --fix`.

## Что работает в приложении

PWA (офлайн, установка), мобильная вёрстка. Кнопка настроек (шестерёнка) — в общей шапке на каждой странице (№63). Нижняя навигация (ветка `feat/nav-profile-app`, решение №28): **Сегодня · Рецепты · Кладовая · Профиль** (иконки: тарелка, кастрюля, банка, человек). Шапка на каждой странице (ветка `feat/app-header`, №29): логотип, счётчик «съедено / норма ккал» за сегодня, кнопка «Приложение» (телефон со стрелкой) → страница `/app`: установка PWA, инструкции для iPhone и Android, «App Store / Google Play — скоро». `/diary` → `/`, `/products` → `/pantry`, `/shopping` → `/pantry?tab=shopping`.

- **Первый запуск** (`/welcome`, ветка `feat/user-profile`, №30): приветствие и анкета по шагам (о вас → активность → цель → норма) с «Позже»; пока анкету не прошли и не отложили, `OnboardingGate` в роутере ведёт на `/welcome`. «Позже» — карточка «Заполните профиль» на «Сегодня».
- **Оформление** (в «Профиле», №39): тема «Авто / Светлая / Тёмная», запоминается (`milo:theme`).
- **Приготовленное блюдо в «Добавить еду»** (№38): порции или граммы; остаток блюда может быть дробным.
- **Профиль** (`/profile`): «Мои данные» — аккордеон со сводкой (№33), раскрытие плавное (`useCollapseAnimation`) (пол, возраст, рост, вес, активность, цель; норма на лету) и «Дневная норма»: по профилю (пересчитывается при сохранении) или «своя» (ручная; «Считать по профилю» возвращает расчёт).
- **Сегодня** (`/`): сводка дня (кольцо калорий, БЖУ), переключение дней, приёмы пищи (бывший «Дневник»): записи по дням, списание с остатка и возврат при удалении; удаление записи о блюде возвращает порцию в «Приготовленные». «Добавить еду» (ветка `feat/meal-from-recipes`): один поиск по приготовленным блюдам (порции или граммы списываются с блюда, №38), рецептам (порции; со списанием продуктов — блюдо в историю как приготовленное и съеденное; без списания — только КБЖУ, источник — рецепт) и продуктам.
- **Рецепты** (`/recipes`): вкладки «Рецепты» / «Приготовленные» / «История» (вкладка в адресе `?tab=`). «Приготовленные» (ветка `feat/cook-recipe`): блюда с остатком порций, «Съесть порцию» (порции + приём пищи → запись на «Сегодня» с источником-блюдом), «Убрать остаток». «История»: по дням — «Приготовлено: …, N порц.» и «Съедено: …, N порц. · приём пищи». Список с поиском; карточка — порции, число ингредиентов, ккал на порцию, бейдж наличия («Всё есть» / «Не всего хватает» / «Нет продуктов»). Создание и правка рецепта: название, порции, ингредиенты — только продукты кладовой (выпадающий список), количество в единице продукта, без дублей.
- **Рецепт** (`/recipes/:id`): выбор порций (− / +, пересчёт количеств), по каждому ингредиенту — нужно / есть / не хватает и статус (Хватает / Частично / Нет), КБЖУ на порцию и всего; «Приготовить» — диалог: что спишется из кладовой, по каждой нехватке обязательный выбор «В покупки» / «Без него» (без автодобавления), затем блюдо в «Приготовленных» (КБЖУ — по фактически использованному); «Недостающее — в покупки» (только по нажатию); «Изменить» (с удалением).
- **Кладовая** (`/pantry`, вкладки «Кладовая» / «Покупки» — `?tab=shopping`): только продукты в наличии («В наличии: N»). Нажатие на остаток в карточке — быстрая правка (−/+, точное число, «Закончилось»). Поиск — по всем продуктам, сначала то, что есть дома; на карточке «+» (в кладовую), корзина (в покупки), ✎. Ничего не найдено → «Создать продукт» с названием из поиска. Единицы г/мл/шт, минимальный остаток, бейджи «Закончился»/«Заканчивается».
- **Предложение «мало»** (виджет `low-stock-prompt` в `RootLayout`, ветка `feat/shopping-low-stock`, №31): когда остаток падает ниже минимума или до нуля (если минимум не задан) — всплывающее «Закончилось / Заканчивается: …» с «В покупки» (недостающее до минимума или типовое количество) и «✕»; не показывается, если продукт уже в списке или его пополнили.
- **Покупки** (вкладка кладовой): круглая галочка в цвете бренда (№32); «Купить» / «Куплено», перенос купленного в кладовую, подсказки «Заканчиваются в кладовой» (без автодобавления).
- Айдентика: знак «м» с мятной точкой, палитра «Орбита», Onest/Unbounded, светлая и тёмная тема; данные в `localStorage` под `milo:*`.
