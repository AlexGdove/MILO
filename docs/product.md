# Продукт MILO

## Видение

MILO (Meal Intelligence & Lifestyle Organizer) — мобильное PWA для питания и образа жизни. Продукт шире подсчёта калорий: дневник питания, кладовая, рецепты и список покупок связаны между собой. В будущем — мобильное приложение, которое можно скачать с сайта; сайтом можно пользоваться и без установки.

## Что уже есть

- Дневник питания по дням и приёмам пищи (завтрак, обед, ужин, перекус).
- Справочник продуктов с КБЖУ на 100 г и остатком в граммах.
- Списание остатка при добавлении приёма пищи и возврат при удалении записи.
- Дневная цель по калориям и БЖУ.
- Сводка дня.
- Работа офлайн и установка на главный экран (PWA).
- Данные хранятся локально в браузере.

## Ключевая идея: кладовая, рецепты, покупки

Пользователь знает, что есть у него дома. При готовке видно, хватает ли продуктов по рецепту. Приготовленное блюдо списывает продукты из кладовой. Если продукт заканчивается, его можно добавить в список покупок. Если при готовке чего-то не хватает, пользователь сам решает: добавить недостающее в список покупок или готовить без него. Ничего не добавляется в покупки автоматически без решения пользователя.

### Кладовая

- Единицы измерения: граммы, миллилитры, штуки. Для штук задаётся вес одной штуки, чтобы считать калории.
- Для каждого продукта можно задать минимальный остаток — ниже него продукт считается заканчивающимся.
- Кладовая показывает только то, что есть дома. Поиск ищет по всем известным продуктам: найденное можно сразу положить в кладовую (указав количество) или добавить в покупки; если продукта нет — создать его с названием из поиска.
- Позже — внешний каталог продуктов и добавление по штрихкоду.

### Рецепты

- Сначала пользователь создаёт свои рецепты локально.
- Позже — рецепты из внешнего API и общая база рецептов от пользователей (потребует бэкенда).
- Источники рецептов подключаются через общий интерфейс источника рецептов, поэтому новые источники не меняют экраны и логику готовки.

## Пользовательские сценарии

1. **Готовлю по рецепту**
   - Открыть рецепт.
   - Увидеть по каждому ингредиенту: есть / хватает частично / нет.
   - Выбрать число порций.
   - Для каждого недостающего выбрать «добавить в покупки» или «готовить без него».
   - Нажать «Приготовить» — доступное количество списывается из кладовой.
   - По желанию записать съеденные порции в дневник.

2. **Покупки**
   - В списке покупок отметить купленное.
   - Нажать «Перенести купленное в кладовую» — остатки увеличиваются.

3. **Заканчивается**
   - Продукт опустился ниже минимального остатка.
   - В кладовой и в списке покупок появляется подсказка добавить его в покупки.

## План развития

1. Документация бренда и продукта.
2. Переименование в MILO с переносом сохранённых данных.
3. Дизайн-токены и шрифты.
4. Знак, иконки, фавикон.
5. Тесты — выполнено: Vitest и React Testing Library.
6. Единицы измерения и минимальный остаток.
7. Список покупок.
8. Рецепты и проверка наличия.
9. Готовка со списанием продуктов.

Навигация после шага 7: Сегодня, Дневник, Рецепты, Кладовая, Покупки. Профиль открывается из шапки.
