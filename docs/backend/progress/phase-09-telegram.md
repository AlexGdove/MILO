## 2. Отклонения от плана и предложения

- **Long polling вместо webhook** (в `architecture.md` был webhook с секретом): на одном VPS проще и безопаснее — нет входящего маршрута. Если понадобится несколько экземпляров сервера — вернуться к webhook.
- **Причина отклонения не выбирается**: поля для неё в схеме нет, приложение видит только статус. Добавить — отдельным решением.
- **Порядок доставки**: если «Обращение № N» не дошло, следующее событие обращения сначала отправит его само (ветка не теряется).

## 4. Что нужно от владельца для сквозной проверки

1. Два бота в @BotFather, две группы (бот + владелец).
2. Токены — в `backend/.env` (`TELEGRAM_SUPPORT_BOT_TOKEN`, `TELEGRAM_MODERATION_BOT_TOKEN`), не в чат.
3. Запустить сервер, написать `/id` в каждой группе → номера групп в `TELEGRAM_*_CHAT_ID`, свой Telegram ID → `npm run operator -- add <ID> <Имя>`.
