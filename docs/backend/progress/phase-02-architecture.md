## 4. Участие локальной модели

Ollama (`qwen2.5-coder:7b`) — черновик Prisma Schema в двух частях по спецификации из `database.md`. Результат пришлось почти полностью переписать: неверный синтаксис enum, нет `@map`/`@@map`, тип `Decimal(8,2)`, отсутствующие поля связей, `Int` вместо uuid у обращения, нет `id` у outbox, несуществующий `@db.Int`. Модель задала структуру моделей; итоговую схему собрал и проверил Claude Code. Архитектура, API и ADR — Claude Code.
