# Mobile

Заготовка мобильного приложения. Цель — дать возможность скачать приложение с сайта
(APK для Android, позже — сторы) или пользоваться PWA.

Варианты реализации:

- **Capacitor** — обернуть сборку `frontend/dist` в нативное приложение (один код);
- **React Native + Expo** — отдельное нативное приложение, общая бизнес-логика и API.
